# Домашнє завдання №4 — Python

## Завдання

1. **task1.py** — обчислює загальну та середню зарплату
   з файлу `salary.txt`.
2. **task2.py** — читає `cats.txt` і повертає список
   словників з інформацією про котів.
3. **task3.py** — показує структуру папки, виділяючи
   папки та файли різними кольорами.
4. **task4.py** — консольний бот для роботи з контактами:
   додавання, зміна номера, пошук і перегляд усіх записів.

## Підготовка

Команди для Windows PowerShell:

    python -m venv venv
    .\venv\Scripts\Activate.ps1
    python -m pip install -r requirements.txt

## Запуск

Виконуйте команди з папки проєкту:

    python task1.py
    python task2.py
    python task3.py "."
    python task4.py

Крапка "." означає поточну папку.
Замість неї можна вказати шлях до іншої папки.

## Команди бота

- hello — привітання.
- add Maryna 0671234567 — додати контакт.
- change Maryna 0501234567 — змінити номер.
- phone Maryna — показати номер.
- all — показати всі контакти.
- exit або close — завершити роботу.

Контакти зберігаються в пам’яті лише під час роботи бота.

## Використано

Python, pathlib, sys, colorama.
